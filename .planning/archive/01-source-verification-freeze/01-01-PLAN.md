    Append a checksum section. Define the get_sha256 macro exactly as in research (the
    doubled `""` produces literal quotes around a path containing spaces — Pitfall 1):

    ```sas
    %macro get_sha256(filepath=, outvar=);
      %global &outvar;
      %let &outvar = ;
      filename _hpipe pipe "certutil -hashfile ""&filepath"" SHA256";
      data _null_;
        infile _hpipe truncover;
        input line $200.;
        line = strip(line);
        if length(line) = 64 then call symputx("&outvar", line, 'G');
      run;
      filename _hpipe clear;
    %mend get_sha256;
    ```

    The `%global` + blank initialisation matters: without it, a failed pipe leaves the
    macro variable undefined and the guard below throws "apparent symbolic reference not
    resolved" instead of the intended error.

    Call it for all eight files:
    ```sas
    %get_sha256(filepath=&source_path.\master_data_1.sas7bdat, outvar=hash_md1);
    /* ... repeat md2..md8 -> hash_md2 .. hash_md8 ... */
    ```
