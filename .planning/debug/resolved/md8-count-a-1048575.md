## Resolution

root_cause: The SAS XLSX engine reads empty numeric Excel cells as 0 (non-missing in SAS),
            not as SAS-missing (.). The 1,026,102 blank padding rows in master_data_8.xlsx
            each have at least one numeric column populated with 0 by the XLSX engine, causing
            the any-column sweep to flag them nonmiss=1. missing(0) = 0 (false) in SAS, so
            all 1,048,575 rows register as non-missing. The self-reference trap (vname fix)
            was a real secondary bug but was not the cause of Count A = 1,048,575.

fix: When src_nobs=22473, Count A reads src.master_data_8 directly instead of the raw XLSX
     file. src.master_data_8 already has blank rows stripped (nobs=22473 proves this). No
     XLSX engine scan is needed. The xlmd8 libname assignment is removed from the src_nobs=22473
     branch. The md8_flags DATA step then sweeps 22,473 clean SAS dataset rows -- no zero-padding
     artifact is possible. The vname fix (row_pos, nonmiss in exclusion list) is retained as
     a correctness safeguard for the src_nobs=1048575 branch.
