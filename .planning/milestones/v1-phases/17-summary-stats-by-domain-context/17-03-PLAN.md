<objective>
Wave 2 (spec §5). On a recoded working copy of work.analysis_base_ext, compute the full
statistic set: PROC MEANS for MEANS-routed variables and PROC FREQ for FREQ-routed variables,
each producing pooled AND per-year results (decision D-03), routed by the stat_route column of
g.var_domain_map from Wave 1. Recode the sentinel forms to missing first — only on the variables
Wave 0 proved actually carry them — and log per-variable recode counts. Apply small-cell
suppression to every subject-level count, pooled and per-year, after statistics are computed and
before anything is written.

Purpose: This is the numeric heart of the phase, and it is gated: Sections 5-11 sit inside
%gate_stats and abort unless Checkpoint 1 set DOMAIN_MAP_APPROVED = 1. Four failure modes live
here. Statistics before sentinel recode silently corrupts every mean, SD, and min. Blanket-recoding
-999 across all numerics destroys legitimate values in variables that never used it as a sentinel.
BY-group processing on an unsorted dataset is a hard abort — use CLASS and TABLES year*var instead,
which also yields pooled and per-year in one pass. And suppressing only the count cell while
printing mean/min/max for a seven-patient block, or printing an unsuppressed n_missing of 7 beside
suppressed levels, defeats the whole suppression rule.
Output: sas/17_summary_stats_by_domain.sas Sections 5-8, producing work.stats_* display datasets
per domain, ready for Wave 3 workbook assembly.
</objective>

2. SCOPE THE SENTINELS. Do NOT recode every numeric. `-999` is a documented sentinel for the
   clock-drawing/dCDT variables; it is not a proven global reserved code across the master data,
   and blanket-applying it would destroy legitimate -999 values anywhere one exists. Read the
   sentinel applicability list produced by Wave 0 — the variables where a `-999` or literal `NULL`

   `proc sql noprint; select varname into :sentinel_num_list separated by ' ' from work.sentinel_applicable where sentinel_kind='NUM_-999'; select varname into :sentinel_chr_list separated by ' ' from work.sentinel_applicable where sentinel_kind='CHAR_NULL'; quit;`
   Recode ONLY these. If the list is empty for a kind, skip that recode via a named macro guard.

3. SINGLE-PASS RECODE. Do not rewrite the whole dataset once per variable — with ~125 variables
   that is ~250 sequential passes and an unreadable log. Count first, then recode all variables in
   one DATA step using arrays inside a named macro:
```sas
%macro recode_sentinels;
  /* counts BEFORE recoding, one row per variable into work.sentinel_log */
  %if %length(&sentinel_num_list) > 0 %then %do;
    proc sql;
      create table work.sentinel_log_num as
      %do i = 1 %to %sysfunc(countw(&sentinel_num_list));
        %let v = %scan(&sentinel_num_list, &i);
        select "&v" as varname length=32, 'NUM_-999' as sentinel_kind length=12,
               (select count(*) from work.analysis_base_clean where &v = -999) as n_recoded
        %if &i < %sysfunc(countw(&sentinel_num_list)) %then %do; union all %end;
      %end;
      ;
    quit;
  %end;
  /* character counts: count ONLY the literal NULL, never `or missing(&v)` --
     including already-missing rows inflates n_recoded with values that were never recoded */
  ...same shape for &sentinel_chr_list with (select count(*) ... where upcase(strip(&v)) = 'NULL')...

  data work.analysis_base_clean;
    set work.analysis_base_clean;
    %if %length(&sentinel_num_list) > 0 %then %do;
      array _sn {*} &sentinel_num_list;
      do _i = 1 to dim(_sn);
        if _sn{_i} = -999 then call missing(_sn{_i});
      end;
    %end;
    %if %length(&sentinel_chr_list) > 0 %then %do;
      array _sc {*} &sentinel_chr_list;
      do _j = 1 to dim(_sc);
        if upcase(strip(_sc{_j})) = 'NULL' then call missing(_sc{_j});
      end;
    %end;
    drop _i _j;
  run;
%mend recode_sentinels;
%recode_sentinels;
```
   Empty strings are already missing to SAS — note that in a comment; do not attempt to recode
   them separately.

   not noise.

Append Sections 6-8.

TYPE ROUTING. Pull the per-domain lists from `stat_route`, not from `vtype`. Routing on vtype alone
sends numeric-coded categoricals (_30_DAY_MORTALITY, sex, ASA class, emergent Y/N) into PROC MEANS,
which reports a meaningless mean for the phase's headline outcome:
`proc sql noprint; select varname into :means_d1 separated by ' ' from g.var_domain_map where domain='D1' and stat_route='MEANS'; select varname into :freq_d1 separated by ' ' from g.var_domain_map where domain='D1' and stat_route='FREQ'; quit;` — repeat for D2-D5.

SECTION 6 — CONTINUOUS. For each domain D1-D5, run PROC MEANS on that domain's MEANS-routed list
with EXACTLY these stats: `n nmiss mean std median p25 p75 min max maxdec=2 stackodsoutput;`
capturing `ods output summary=work.means_<d>;`.

USE `class &year_variable;` — NOT `by &year_variable;`. A BY statement requires the input sorted by
that variable; work.analysis_base_clean descends from a dataset sorted by PRECEDE_STUDY_ID, so a BY
year would abort with "BY variables are not properly sorted". CLASS needs no sort. It also emits the
pooled row and every per-year row in a single pass:
```sas
proc means data=work.analysis_base_clean n nmiss mean std median p25 p75 min max
           maxdec=2 stackodsoutput;
  var &means_d1;
  class &year_variable;
  types () &year_variable;   /* () = pooled overall, &year_variable = one row per year */
  ods output summary=work.means_d1;
run;
```
Build the release-safe statistic column list from dictionary.columns (copy lines 456-465 of
16_summary_docx.sas) because the SD column is StdDev in some releases and Std in others. Guard: if a
domain has an empty MEANS list, skip its call via a named macro (%if count=0 %then %return).

SECTION 7 — CATEGORICAL. For each domain D1-D5, run PROC FREQ on that domain's FREQ-routed list
with `/ missing nocum;` capturing `ods output onewayfreqs=work.freq_<d>_pooled;`. For the per-year
block use crosstabs rather than BY — again no sort required:
`tables (&freq_d1) * &year_variable / missing nocum norow nocol nopercent; ods output crosstabfreqs=work.freq_<d>_year;`
Then transform both outputs into ONE standardized long structure before any display work:
`varname | level | year (blank = pooled) | frequency | n_nonmissing | n_missing | pct_nonmissing`
Computing percentages against a long table is straightforward and avoids the level-by-variable
cartesian blowup that comes from transposing ONEWAYFREQS output across many variables. Percent is
recomputed on the NON-MISSING denominator per D-02 — do NOT use the raw ODS Percent, which includes
missing. Concretely: split each table into a missing-count row (level value missing) and non-missing
level rows, derive n_nonmissing per variable-year, then `pct_nonmissing = 100 * frequency / n_nonmissing`.
Pivot to wide only at the display stage in Section 8.

SECTION 8 — SUPPRESSION. Read `&SUPPRESS_MAX` (11) and `&SUPPRESS_LABEL` (--) from Section 0. Never
hardcode `<11` as a display string: under an n <= 11 rule a cell of exactly 11 labelled "<11" is a
false statement. Apply suppression in a single post-statistics pass per display dataset, to BOTH
pooled and per-year cells:

  a. CATEGORICAL LEVEL COUNTS. `if frequency <= &SUPPRESS_MAX then do; n_display="&SUPPRESS_LABEL"; pct_display="&SUPPRESS_LABEL"; suppressed=1; end;`
  b. N_MISSING. Suppress it on the same rule. A sheet reading "Male 5,120 / Female 4,832 / Missing 7"
     discloses a small cell just as plainly as an unsuppressed level would.
  c. CONTINUOUS BLOCKS — WHOLE ROW. If a continuous variable's non-missing n for a block (pooled or
     any single year) is <= &SUPPRESS_MAX, suppress EVERY statistic for that variable-block: mean,
     SD, median, Q1, Q3, min, max, and n itself. Min and max on seven patients are more disclosive
     than the count you suppressed. Showing "n=--" beside a real mean and min defeats the rule.
  d. COMPLEMENTARY DISCLOSURE. Where a variable has exactly one suppressed level and the block total
     is printed, the suppressed count is back-calculable. When only one level in a variable-block is
     suppressed, suppress the next-smallest level as well.
  e. Set suppressed=1 on every affected cell and accumulate the total into `:n_suppressed` for the
     QC sheet. Non-suppressed formatting: `n_display=strip(put(frequency,comma12.)); pct_display=strip(put(pct_nonmissing,6.1));`

Suppression missed on per-year cells is an explicit pitfall (17-RESEARCH.md Pitfall 3) — apply the
same pass to every year block, not only pooled.

Produce, per domain, a continuous display dataset and a categorical display dataset (pooled and
per-year columns) ready for Wave 3 PROC REPORT. Do not open ODS EXCEL here — that is Wave 3.
