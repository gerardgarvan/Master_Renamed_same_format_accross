Purpose: Phase 4 merge must receive md8 with clean numeric types and no sentinels so it can merge on the md3 spine without any further type work (PREP-03).
Output: `sas/03_prep_md8.sas`, and at run time `g.prep_md8`, `qc/03_exceptions_md8.txt`, `logs/03_conversions_md8.txt`.

SECTION 3 — Two-step normalization.

Step 1 (sentinel clear) — LENGTH block FIRST (from qc/03_charvars_all.txt widths), then SET, then array clear:
```sas
data work.prep_md8_s1;
  length
    PRECEDE_STUDY_ID $12
    /* Declare EVERY md8 character variable here at its source width from
       qc/03_charvars_all.txt. Include the eight forced-char numerics at
       their CHAR widths (Admit_BMI $11, ASA__Anesth_Record_ $4, etc.) --
       they are still character at this stage. */
    ;
  set src.master_data_8;
  array _charv {*} _CHARACTER_;
  do _i = 1 to dim(_charv);
    if strip(upcase(_charv{_i})) = 'NULL' then _charv{_i} = ' ';
  end;
  drop _i;
run;
```
