Pattern: named macro wrapping %abort cancel
```sas
%macro assert_eq(actual=, expected=, label=);
  %if &actual ne &expected %then %do;
    %put ERROR: &label = &actual, expected &expected;
    %abort cancel;
  %end;
  %put NOTE: &label = &actual (assertion passed);
%mend assert_eq;
```

Pattern: COUNT INTO TRIMMED (never &SQLOBS)
```sas
proc sql noprint;
  select count(*) into :macvar trimmed
  from g.master_data_merged
  where <condition>;
quit;
```

Pattern: libname, WRITABLE, with the existence guard inside a named macro
```sas
/* The g library must be WRITABLE -- SECTION 2 writes g.analytic_cohort into it.
   ACCESS=READONLY would make the whole library read-only and that DATA step
   would fail with "Library G is read only". Read-only intent toward the SOURCE
   is enforced by never naming g.master_data_merged on the left of a DATA
   statement, which is how 06_reconcile.sas does it. */
libname g "&g_path";

/* PCM-R-05: %abort cancel must be inside a NAMED macro, never in open code.
   A bare %if ... %abort in open code violates the rule this project enforces. */
%macro check_source_exists;
  %if not %sysfunc(exist(g.master_data_merged)) %then %do;
    %put ERROR: g.master_data_merged not found. Run Phases 3-5 first.;
    %abort cancel;
  %end;
  %put NOTE: PRECONDITION OK -- g.master_data_merged present.;
%mend check_source_exists;
%check_source_exists;
```

Pattern: QC file path -- the trailing dot is consumed, so write the backslash
```sas
/* CORRECT -- yields ...\merge\qc\07_cohort_missingness.txt */
ods listing file="&qc_path.\07_cohort_missingness.txt";

/* WRONG -- yields ...\merge\qc07_cohort_missingness.txt, no separator */
ods listing file="&qc_path.07_cohort_missingness.txt";
```

Pattern: writing prose into the same QC file WITHOUT truncating it
```sas
/* ODS LISTING FILE= OVERWRITES on every open. Do not open it twice on the same
   path expecting to append. Use the 06_reconcile.sas pattern for prose: */
data _null_;
  file "&qc_path.\07_cohort_missingness.txt" mod;
  put "admitted_n=&n_admitted";
run;
```
