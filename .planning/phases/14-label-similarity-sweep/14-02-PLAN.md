Write results to work.value_inventory:

```sas
/* SSDI group value inventory */
proc sql noprint;
  create table work.ssdi_inv as
  select 'SSDI_DEATH_DATE_Y_N' as varname length=32,
         strip(put(SSDI_DEATH_DATE_Y_N, $32.)) as value length=32,
         count(*) as n_rows
  from g.master_data_harmonized
  group by SSDI_DEATH_DATE_Y_N
  having count(*) >= 0
  UNION ALL
  select 'SSDI_DEATH_Y_N' as varname,
         strip(put(SSDI_DEATH_Y_N, $32.)) as value,
         count(*) as n_rows
  from g.master_data_harmonized
  group by SSDI_DEATH_Y_N
  UNION ALL
  select 'SSDI_DEATH' as varname,
         strip(put(SSDI_DEATH, $32.)) as value,
         count(*) as n_rows
  from g.master_data_harmonized
  group by SSDI_DEATH
  order by varname, n_rows desc;
quit;
```

Note: Because the SAS variable types (character vs numeric) for SSDI variables are not
confirmed in the research, use a TYPE-safe approach. Read the type from dictionary.columns
before building the query. If any SSDI variable is numeric, replace $32. with the correct
numeric format. The safest SAS 9.4 approach for mixed-type grouping in a single query is
separate queries unioned. The PUT(x, $32.) call works for character variables; for numeric
use PUT(x, best32.). Check dictionary.columns.type ('char' or 'num') for each variable
before choosing the format string.

Practical implementation: Run the UNION ALL query above; if it fails with a type error,
replace put(SSDI_DEATH_DATE_Y_N, $32.) with put(SSDI_DEATH_DATE_Y_N, best32.) for the
offending column (only one format change needed per numeric variable).

```sas
/* CPT1 group value inventory -- 159 distinct values each; no cap on inventory itself */
proc sql noprint;
```

Step B-3: Pairwise cross-tabulation (overlap analysis).

For SSDI group: compute n_both, n_a_only, n_b_only for each column pair.
Three pairs: (SSDI_DEATH_DATE_Y_N, SSDI_DEATH_Y_N), (SSDI_DEATH_DATE_Y_N, SSDI_DEATH), (SSDI_DEATH_Y_N, SSDI_DEATH).

```sas
proc sql noprint;
  create table work.ssdi_xtab as
  select 'SSDI_DEATH_DATE_Y_N' as varname_a length=32,
         'SSDI_DEATH_Y_N'      as varname_b length=32,
         strip(put(SSDI_DEATH_DATE_Y_N, $32.)) as value_a  length=32,
         strip(put(SSDI_DEATH_Y_N,      $32.)) as value_b  length=32,
         count(*) as n_rows
  from g.master_data_harmonized
  group by SSDI_DEATH_DATE_Y_N, SSDI_DEATH_Y_N
  UNION ALL
  select 'SSDI_DEATH_DATE_Y_N', 'SSDI_DEATH',
         strip(put(SSDI_DEATH_DATE_Y_N, $32.)),
         strip(put(SSDI_DEATH,          $32.)),
         count(*)
  from g.master_data_harmonized
  group by SSDI_DEATH_DATE_Y_N, SSDI_DEATH
  UNION ALL
  select 'SSDI_DEATH_Y_N', 'SSDI_DEATH',
         strip(put(SSDI_DEATH_Y_N, $32.)),
         strip(put(SSDI_DEATH,     $32.)),
         count(*)
  from g.master_data_harmonized
  group by SSDI_DEATH_Y_N, SSDI_DEATH
  order by varname_a, varname_b, n_rows desc;
quit;
```
