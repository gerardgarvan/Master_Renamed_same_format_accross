<objective>
Wave 2 (spec §5). On a recoded working copy of work.analysis_base_ext, compute the full
statistic set: PROC MEANS for continuous variables and PROC FREQ for categorical variables,
each run pooled AND per-year (decision D-03), routed by variable type per the domain map from
Wave 1. Recode the three sentinel forms to missing first and log per-variable recode counts.
Apply small-cell suppression (≤11) to every count cell, pooled and per-year, after statistics
are computed and before anything is written.

Purpose: This is the numeric heart of the phase. Getting the order wrong — statistics before
sentinel recode — silently corrupts every mean, SD, and min. Missing suppression on a per-year
cell leaks a small count. Routing a character variable into PROC MEANS is a fatal error.
Output: sas/17_summary_stats_by_domain.sas Sections 5-8, producing work.stats_* display datasets
per domain, ready for Wave 3 workbook assembly.
</objective>

(from g.var_domain_map, vtype='num') with EXACTLY these stats:
`n nmiss mean std median p25 p75 min max maxdec=2 stackodsoutput;` capturing `ods output summary=work.means_<d>_pooled;`.

SECTION 7 — CATEGORICAL. For each domain D1-D5, run PROC FREQ on that domain's character list
with `/ missing nocum;` capturing `ods output onewayfreqs=work.freq_<d>_pooled;`. Repeat with
`by <year_variable>;` for `work.freq_<d>_year`. Then transform each freq output into the required
shape: for every non-missing level compute n and pct_of_nonmissing (percent recomputed on the
NON-MISSING denominator per D-02, NOT the raw Percent which includes missing), and carry the
missing level's frequency into a separate n_missing column. Concretely: split each ODS
ONEWAYFREQS table into a missing-count row (where the level value is missing) and non-missing
level rows, then `pct_nonmiss = 100 * n_level / n_nonmiss_total` per variable.

SECTION 8 — SUPPRESSION. In a single post-statistics DATA step per display dataset, replace any
count ≤ 11 with the display string `<11` and blank/suppress its paired percent, for BOTH pooled

macro variable :n_suppressed for the QC sheet. Pattern (17-RESEARCH.md Pattern 6):
`length n_display $12 pct_display $12; if n_count <= 11 then do; n_display='<11'; pct_display='<11'; suppressed=1; end; else do; n_display=strip(put(n_count,comma12.)); pct_display=strip(put(pct,6.1)); suppressed=0; end;`
Apply this to per-year count columns as well — suppression missed on per-year cells is an
explicit pitfall (17-RESEARCH.md Pitfall 3).

Produce, per domain, a continuous display dataset and a categorical display dataset (pooled and
per-year columns) ready for Wave 3 PROC REPORT. Do not open ODS EXCEL here — that is Wave 3.
