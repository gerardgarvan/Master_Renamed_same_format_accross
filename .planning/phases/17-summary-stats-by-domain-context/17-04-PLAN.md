<objective>
Wave 3 (spec §5). Assemble the single deliverable workbook with ODS EXCEL: KEY sheet leftmost,
then D1-D5 domain sheets from the Wave 2 display datasets, then Crosswalk and QC sheets. Apply
UF colors to header rows. Write the parallel QC text artifact. Restore the log. End at a blocking
human review of the issued workbook against the data dictionary (Checkpoint 2).

consumes. KEY-leftmost and UF colors are project conventions (CLAUDE.md). The QC sheet is where
the phase proves it did what it claims — recode counts, suppression counts, per-rule assignment
counts. A locked prior workbook or a missing KEY tab are known pitfalls.

and Checkpoint 2 approval.

SECTION 9 — WORKBOOK. First a `%drop_stale` macro deleting a prior qc\17_summary_stats_by_domain.xlsx

new file name). Then:

1. `ods listing close;` and open ODS EXCEL ONCE:
   `ods excel file="&qc_path.\17_summary_stats_by_domain.xlsx" options(sheet_name="KEY" embedded_titles="yes" autofilter="all" frozen_headers="1");`
2. KEY sheet FIRST (makes it leftmost). Build a work.key dataset (item/detail rows) and PROC REPORT
   it with `style(header)=[background=CX0021A5 color=white fontweight=bold]`. Include: legend of
   the statistic set, dataset name (work.analysis_base_ext derived from g.analysis_base +
   g.master_data_merged), run datetime, row count (&n_base_rows), suppression rule (cells <=11
   shown as <11), denominator rule (percent on non-missing per D-02), and the scope statement
   (descriptive only, no inferential testing).
3. D1 through D5: for each domain switch sheet with `ods excel options(sheet_name="D1");` (D2..D5
   likewise) and PROC REPORT the domain's continuous display dataset then its categorical display
   dataset, both with the UF blue header style. Columns include the pooled block AND the per-year
   blocks from Wave 2. Add the D5 note about _30_DAY_MORTALITY missingness reflecting the md1 join,
   not the outcome (pitfall 6).
4. Crosswalk sheet: `ods excel options(sheet_name="Crosswalk");` PROC REPORT g.var_domain_map with
   columns varname, sas_label (dictionary label), vtype, source_dataset, domain, domain_rationale —
   ordered by domain then varname, UF blue header.
5. QC sheet: `ods excel options(sheet_name="QC");` PROC REPORT a work.qc_summary dataset built from:
   source dataset name, row count, run datetime, total sentinel recodes (sum of work.sentinel_log),
   :n_suppressed, count of variables per domain (from g.var_domain_map), and count of variables by
   each of the three assignment rules (assign_rule in 'timing'/'analytic_role'/'instrument').
6. `ods excel close; ods listing;`

SECTION 10 — QC TEXT ARTIFACT. `data _null_; file "&qc_path.\17_summary_stats_by_domain.txt"; ...`
writing the same QC facts as plain text (run datetime, source, row count, per-domain counts,
per-rule counts, total recodes, suppressed cells, OUT_OF_SCOPE count). No apostrophes or embedded
semicolons in any %PUT.

SECTION 11 — `%restore_log;` and a final existence check macro (%check_xlsx) that %fail_out if the
xlsx was not written.

All conditional logic in named macros; %abort cancel only via %fail_out.
