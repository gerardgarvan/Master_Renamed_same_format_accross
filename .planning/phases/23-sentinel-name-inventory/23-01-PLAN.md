Hex key macro (define in 00_config.sas; used here AND by Phase 24 gate — identical text):
```sas
%macro hexkey(var);substr(put(&var, $hex400.), 1, 2*length(&var))%mend hexkey;
```
Note: no `/` after the parameter list (that introduces macro OPTIONS such as /store and is a
syntax error here), and no semicolon inside the body, so `raw_hex = %hexkey(raw_value);`
expands to a single expression. Assign `length raw_hex $400;` before first use.
$hex400. covers values up to 200 bytes; SECTION 0 asserts max char length <= 200 (see Task 2).
CRITICAL: bare `$hex.` (default width 4) encodes only the first 2 bytes — `UNKNOWN` and `UNK`
both become 554E, and -999 / -99 both become 2D39. All keys collide. Never use bare `$hex.`.

Character raw_hex:  raw_hex = %hexkey(raw_value);
Numeric raw_hex:    raw_hex = %hexkey(strip(put(x, best32.)));   /* hex of the TEXT, not float bytes */

candidate_class enum (clean, three values only): AUTO / REVIEW / AMBIGUOUS
non_ascii_flag: separate boolean column (0/1), does NOT modify candidate_class.
role: KEY / KEEP / DROP carried from the name-map draft logic into the candidates CSV.
column_group: DEMOGRAPHIC / SCORE / blank.

qc/23_sentinel_candidates.csv columns (order):
  variable, raw_value, raw_hex, raw_len, normalized_value, var_type, n_rows, pct_rows,
  column_group, candidate_class, non_ascii_flag, match_rule, role
