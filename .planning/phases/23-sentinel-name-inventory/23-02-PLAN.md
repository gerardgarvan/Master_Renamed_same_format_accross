<truncation_algorithm>
<!-- PCM-D-23. Confirmed at Plan 03 checkpoint before this draft is authoritative. -->
1. If length("pcnr_" || name) <= 32: no truncation. final = "pcnr_" || name.
2. Else: final = "pcnr_" || head || "_" || final_token
   - final_token = substring after the LAST underscore in the (h_-stripped) source name
   - head budget = 32 - 5(pcnr_) - 1(joining _) - length(final_token)
   - head = source name minus final_token and its underscore, trimmed to the head budget
   - STRIP any trailing underscore from head before rejoining (avoids double __ and empty token)
3. FALLBACK to plain tail truncation to 32 chars total when ANY of:
   - the name has no underscore, OR
   - final_token alone is > 12 chars, OR
   - final_token is empty after stripping (source name ends with _)
4. collision_flag = 1 if final_name matches any other row case-insensitively.

Worked example: rt_BLOCK_START_TO_BLOCK_END_mins (32)
  final_token = mins (4); head budget = 32-5-1-4 = 22
  head = rt_BLOCK_START_TO_BLOCK_END (27) trimmed to 22 = rt_BLOCK_START_TO_BLOC
  result = pcnr_rt_BLOCK_START_TO_BLOC_mins (32 chars) ✓
</truncation_algorithm>
