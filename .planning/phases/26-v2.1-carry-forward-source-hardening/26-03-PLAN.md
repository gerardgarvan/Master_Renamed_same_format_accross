    The section:
    1. Reads the baseline with a DATA step `infile` (PCM-T-16), NOT PROC IMPORT:
    ```sas
    data work._baseline;
      length file_name $200 sha256 $64 byte_size 8 seeded_date $12;
      infile "&docs_path.\raw_hash_baseline.csv" dsd dlm=',' firstobs=2 truncover;
      input file_name $ sha256 $ byte_size seeded_date $;
    run;
    ```
    1b. Fail clearly if the baseline is absent (otherwise the infile ERROR is the only message), and require exactly 8 baseline rows. Put both checks in a named macro before the infile step:
    `%if not %sysfunc(fileexist("&docs_path.\raw_hash_baseline.csv")) %then %fail_out(msg=HARD-01 baseline docs/raw_hash_baseline.csv not found -- run 19b once to seed it);`
    and after the read, `%fail_out` if the row count is not 8.

    2. Joins the baseline to the CURRENT md1-md8 sha256 values in work.files_out -- restricted to rows whose full_path is in the md-master directory (the same directory SECTION 11b checks), because raw\ holds other copies and a same-named file elsewhere would duplicate the join and report false drift. Compare lowercase on BOTH sides (certutil output case is not guaranteed). Per Pitfall 4 match on filename, not a session-specific sequence. Count drift:
    ```sas
    %macro check_hash_baseline;
      %local n_drift;
      %let n_drift = 0;
      proc sql noprint;
        select count(*) into :n_drift trimmed
        from work._baseline b
        left join (select * from work.files_out
                   where upcase(full_path) like upcase("&raw_path.\master\%")) f
          on upcase(strip(b.file_name)) = upcase(strip(f.filename))
        where lowcase(strip(b.sha256)) ne coalesce(lowcase(strip(f.sha256)), 'missing');
      quit;
      %if &n_drift > 0 %then %do;
        %fail_out(msg=HARD-01 HASH GUARD FAILED -- &n_drift md1-md8 source file(s) changed since baseline. Delete docs/raw_hash_baseline.csv and re-run 19b to acknowledge new sources.);
      %end;
      %put NOTE: HARD-01 hash guard passed -- all md1-md8 sha256 values match baseline.;
    %mend check_hash_baseline;
    %check_hash_baseline;
    ```
    Reuse the existing %fail_out macro (PCM-R-05). Program 19 must NEVER write raw_hash_baseline.csv — read only (D-10). NOTE: program 19 is NOT first in run_pipeline.cmd today -- the Phase 25 order is 01-08, then 19, 20, 10b, 16b, 23-25, 17, 18. Task 2b moves it.
  </action>
