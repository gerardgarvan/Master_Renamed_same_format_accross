De-dup rule encoding pattern — keep-first by sort order:
```sas
proc sort data=work.r1_normed nodupkey dupout=work._r1_dup_check;
  by PRECEDE_STUDY_ID;
run;
/* After sort, work.r1_normed has unique keys; work._r1_dup_check holds dropped rows */
```

De-dup rule encoding pattern — keep row where specific column is non-missing:
```sas
proc sort data=work.r1_normed;
  by PRECEDE_STUDY_ID descending col_x;  /* non-missing col_x sorts first */
run;
proc sort data=work.r1_normed nodupkey dupout=work._r1_dup_check;
  by PRECEDE_STUDY_ID;
run;
```

Post-dedup gate (must be inside named macro — PCM-R-05):
```sas
%macro r1_dup_gate;
  %let _r1_n = 0;
  proc sql noprint;
    select count(*) into :_r1_n trimmed from work._r1_dup_check;
  quit;
  %if &_r1_n > 0 %then %do;
    %fail_out(msg=r1 still has &_r1_n duplicate PRECEDE_STUDY_ID rows after de-dup -- resolve PCM-D-29 before merge);
  %end;
%mend r1_dup_gate;
%r1_dup_gate;
```

Final keep step (approved columns only):
```sas
data work.r1_prepped;
  set work.r1_normed (keep=PRECEDE_STUDY_ID col_a col_b ...);  /* approved column list */
run;
```

md8_donors naming pattern for merge block (from sas/04_merge.sas MRG-06):
```sas
/* Rename columns with _r1_ prefix to avoid PDV collision in the merge DATA step */
data work.r1_donors;

run;
proc sort data=work.r1_donors; by PRECEDE_STUDY_ID; run;
```
