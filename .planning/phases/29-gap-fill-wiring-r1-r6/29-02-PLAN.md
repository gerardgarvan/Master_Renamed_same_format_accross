**Key normalization corrections (apply to ALL six files before de-dup):**

r2 prefix must be CONDITIONAL, not unconditional. If studyid already starts with 'PRECEDE', adding the prefix again produces "PrecedePrecede…":
```sas
/* r2: conditional prefix (same rule as r1/r3/r5/r6 -- NOT unconditional) */
data work.r2_normed;
  length PRECEDE_STUDY_ID $12;
  set work.r2_s1 (keep=studyid rename=(studyid=_k_raw));
  if index(upcase(strip(_k_raw)), 'PRECEDE') = 0
    then PRECEDE_STUDY_ID = 'Precede' || strip(_k_raw);
    else PRECEDE_STUDY_ID = 'Precede' || substr(strip(_k_raw), 8); /* strip existing Precede/PRECEDE prefix, re-add correct case */
  drop _k_raw;
run;
```

The ELSE branch for all char-key files (r1, r2, r3, r5, r6) must normalize case, not pass through raw:
- Wrong: `else PRECEDE_STUDY_ID = strip(_k_raw);` — keeps "PRECEDE12345" uppercase, silently misses join
- Correct: `else PRECEDE_STUDY_ID = 'Precede' || substr(strip(_k_raw), 8);` — strips whatever prefix is there and re-adds 'Precede' with correct case
