WHAT THIS MEASURES
  recoverable  = rows where the OWNER is missing and a DONOR has a value.
                 These are values the KEEP= ownership merge DISCARDS.
  disagree     = rows where both have a value and the values DIFFER.
                 Non-zero means coalescing is a DECISION, not a gap-fill.
                 CHARACTER variables use exact inequality. NUMERIC variables
                 use abs(a-b) > 1e-8, so floating-point representation noise
                 between two exports is not reported as a conflict.
  both_present = rows where both have a value (the disagreement denominator).

  omitted md8. It was wrong -- Cognitive_Score and Frailty_Score were each
  losing 8-9k values, and three more variables were found only by sweeping
  all of md3/md8 rather than guessing which to test.
